## Causes and changes

- Read-only inventory of the actual phone APKs found Fluidify2.0.1/code24 and
  ClasseViva7.16.1/code2026110501 without the four `source_*` tools or proof contract.
  This differs from the source checkouts and historical candidate APKs.
- Discovery previously discarded incompatible or unavailable sources. Known installed
  package IDs now remain visible with update, account, signature or availability status.
  Listing a package grants no read permission. The exact host, signature, typed-v2,
  source-proof-v1, scope/account, lease and explicit-consent checks remain mandatory.
- The settings-category `BackHandler` performed an ordinary pop while intercepting
  predictive events. Fluid now owns that back route. Profile-area editing uses a real
  nested page stack, preserving its outgoing content through cancellation/settling.
- The anchored bar explicitly consumed every pointer event while `isMoving` and
  disabled its callbacks. Controls now target the requested stack top during motion.
  Departing actions stay drawn but cannot execute or expose duplicate accessibility
  actions. Covered page-body protections remain in place.
